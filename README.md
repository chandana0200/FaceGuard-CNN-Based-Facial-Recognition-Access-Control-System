# FaceGuard — CNN-Based Facial Recognition Access Control System

Built as part of the ELE8100 CyberAI module, MSc Applied Cybersecurity, 
Queen's University Belfast.

## Overview
A CNN-based facial recognition system that authenticates 40 individuals from 
grayscale images and restricts server room access to authorised personnel only.

## Results
- Achieved 99.5% test accuracy
- Implemented access control decision logic on top of model predictions

## Tech stack
Python, PyTorch, CNN, Deep Learning
